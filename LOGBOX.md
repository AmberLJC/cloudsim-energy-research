| 9 | Analysis / NULL RESULT | **Primary claim FAILS.** D-PABFD shows −0.24% to −0.35% vs PABFD (slightly WORSE). Null hypothesis NOT rejected. **Mechanism identified (key finding):** For linear power models P=a+b×u, ΔE_compute is CONSTANT regardless of which active host receives the VM. Therefore, D-PABFD's criterion (argmin ΔE×PUE) is DEGENERATE — all active hosts are tied. D-PABFD breaks ties arbitrarily (last host in list), while PABFD always picks the highest-utilization host → more consolidated → slightly better. **This is analytically provable:** total DC energy = [Σ_h P(u_h)] × PUE(u_DC). For linear P and linear PUE, placing a VM on any active host changes total energy by the same amount (proven in analysis.md). D-PABFD would only outperform PABFD with non-linear power models (quadratic) or non-linear PUE (ASHRAE piecewise). **Publishable finding:** "For linear power and PUE models, no scheduling algorithm outperforms PABFD — the null result has an analytic explanation." | 2026-02-27 |
